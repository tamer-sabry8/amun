Idea to Done · one flow for Products and Projects

The requirements for approval, drawn as a flow with the screen at each step. The full text is docs/plans/2026-11-23-idea-to-done-requirements.md. Nothing is built yet; each screen still gets its own before/after before coding.

Idea→PRD / BRD (approved version)→Epics→Stories→Sprint→Release→Roadmap item

Every piece remembers the piece above it. Progress flows up by itself; closing anything in Jira, Linear or Azure DevOps always needs your one approval.
