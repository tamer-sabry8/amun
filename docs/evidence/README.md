# Evidence requirements

Create one directory per task ID. Record the commit, OS/toolchain, exact commands and exit status, test counts, red failure before implementation, green results after implementation, and remaining DoD checks. Red must fail for the intended missing behavior. Never commit credentials or private service data.

Unit success does not imply integration success. Label live, fixture, skipped and unrun checks separately. Record screenshots and accessibility/performance measurements on macOS for native UI. A task stays unchecked until all its acceptance evidence exists.
