# T052 stakeholder updates

The initial regression failed because there was no stakeholder draft service. The service generates source-cited work status and acceptance verdicts, with explicit unknowns for missing evidence. Export approval binds the final redacted title, text, product or portfolio scope, operation and PDF destination. Replayed approval, changed text and a foreign product are refused.

A real Mac app drafted an update from a synthetic story, cited its work-item ID, and marked the missing acceptance verdict unknown. Editing the text removed the approval control. The export directory did not exist before approval. After a fresh exact review and approval, the app produced one PDF with a valid file signature using the Mac print filter. Notion publication uses the existing verified destination, reviewed publication ID and durable outbox.

A separate run of the production Mac exporter generated a synthetic update and extracted its PDF text. The title, work-item citation and explicit unknown acceptance verdict survived conversion.

After the owner reviewed the synthetic stakeholder update, its exact title, body, publication footer and Document Hub destination matched the saved review. The Mac service sent one approved create and verified the receipt against the parent and marker. An independent live fetch confirmed the story citation, unknown verdict and footer in the published body.
