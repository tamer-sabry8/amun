You approved fork with the stop card on 19 November 2026. These are the three places it shows. The pictures are the real conversation screen with the new parts drawn on top; nothing is built yet. Everything still goes through Firstmate.

1. The icons under a message

Workflow it enables: start a second chat from any earlier message, as in your screenshot.

  • The icons show only on the message you point at, or reach with the keyboard.
  • Nothing is added to the message box.

2. Chats in folders on the left (your note)

Workflow it enables: see every chat at a glance, grouped by what it belongs to, and move between a main chat and its forks in one click.

  • Each piece of work is its own folder, under its own name (for example MoCA Ecabinet), whether it is a product, a project, a task or an RFP. There are no type headings.
  • Open a folder to see its chats: the main chat, then each fork named after the message it started from. The chat you are in is highlighted.
  • General comes last and holds “Chat with Firstmate” and anything that belongs to no work.
  • Only the group you are working in (Work, Personal) is listed, as everywhere else in Amun.
  • The eight tiles, Firstmate's card and the bottom row stay where they are. When the sidebar is collapsed the folders are hidden.

Two things I assumed and would like you to confirm: the folders are in the order you last used them, newest first; the list scrolls on its own when it is long, so Firstmate's card always stays in view.

3. The stop card

Workflow it enables: when crew work was started after the point you forked from, you decide whether it keeps running.

  • Stop it sends Firstmate a request to stop that crewmate. Amun never stops crew itself.
  • Leave it running closes the card and changes nothing.
  • The card shows only when work was started after the fork point and is still running.

What does not change

  • No Resume button. You continue any chat by typing in it.
  • The original chat is never changed by a fork.
  • Firstmate keeps one memory. A fork tells Firstmate which messages to set aside; it does not rewind Firstmate.
