P5-3. Isolation guarantees and deferred visual scope

Confirm the security boundary for loopback previews and confirm that interactive RICE sorting and Gantt timeline bars remain deferred to a later decision (Markdown tables + existing Roadmap view stay in place for Phase 6).

Security & Scope Gate
Control Phase 5 behavior Verification test
Lineage check on open Server verifies output exists, belongs to the authorized work area/group, has type === "prototype", and contains a valid self-contained HTML page (≤ 500 KB) before issuing a preview URL. Cross-group / deleted / non-prototype requests rejected.
Loopback token & TTL Bound to 127.0.0.1 only, 256-bit random path token, Host header check, 15-minute TTL, cap of 8 active previews (evicting oldest), closed on pane/window/daemon exit. Wrong host, wrong path, expired token, and post-close all return 404.
Strict offline CSP & session default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:; font-src data:; form-action 'none'; frame-ancestors 'none'; base-uri 'none'. Ephemeral memory-only Electron partition with zero preload, zero cookies, zero external navigation. Synthetic clicks work; external fetch/navigation and desktop IPC fail.
Deferred visual panes Interactive RICE column sorting and interactive Gantt bars stay deferred. Firstmate produces sorted RICE tables and phase/Gantt tables in Markdown; quarterly roadmaps use the existing Roadmap pane. No new top-level views, no composer changes, ~0 MB app growth.
